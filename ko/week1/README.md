# 🛠️ 1주차 실습: 직선운동 문제 풀이 (Rectilinear Motion)

> **Author / Rights Holder:** 전북대학교 생물산업기계공학과 유동수 (ryudongsoo@jbnu.ac.kr)

[뒤로가기(한국어 메인)](../README.md)

본 폴더는 **생물역학 1주차 강의**에서 다룬 직선운동(예제 및 연습문제)을 파이썬(Python)으로 직접 시뮬레이션하고 시각화(애니메이션) 해보는 실습 자료입니다.

## 📌 실습 개요 및 목표

- **직선운동의 시각적 이해**: 시간에 따른 위치($s$), 속도($v$), 가속도($a$)의 변화를 그래프와 입자의 움직임으로 동시 관찰
- **운동 방정식의 코드화**: 강의에서 배운 수식(미분 및 적분 관계)을 Python 함수로 구현
- **과제 해결 능력 배양**: 주어진 조건에서 물리적 한계를 모델링하고 프로그래밍하는 훈련

## 💻 제공되는 시뮬레이션 코드

아래의 파이썬 파일들은 수업 시간에 함께 푼 문제들을 시뮬레이션합니다. 코드를 실행하면 애니메이션 창이 팝업됩니다.

| 파일명 | 대상 문제 | 내용 |
|--------|---------|------|

| `ex2_3_spring.py` | 예제 2.3 | 가속도가 위치의 함수($a = -k^2 s$)인 조화 진동 |
