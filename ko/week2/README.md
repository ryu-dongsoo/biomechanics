# 🛠️ 2주차 실습: 포물체 운동 문제 풀이 (Projectile Motion)

> **Author / Rights Holder:** 전북대학교 생물산업기계공학과 유동수 (ryudongsoo@jbnu.ac.kr, ryudongsoo@gmail.com)

[뒤로가기(한국어 메인)](../README.md)

본 폴더는 **생물역학 2주차 강의**에서 다룬 직교좌표계 곡선운동 및 포물체 운동을 파이썬(Python)으로 직접 시뮬레이션하고 2D 평면 궤적을 시각화(애니메이션) 해보는 실습 자료입니다.

## 📌 실습 개요 및 목표

- **2차원 곡선운동의 직교 성분 분리**: 곡선 궤적 상의 물체 운동을 $x$축과 $y$축 방향의 독립적인 1차원 운동으로 분해하여 해석
- **포물체 운동 시뮬레이션**: 지면 발사체, 비행기 투하 우편물, 터널 내부 발사체 등 중력(-g)의 영향을 받는 다양한 포물체 궤적 모델링
- **과제 해결 능력 배양**: 주어진 제약 조건(목표 높이, 사거리, 충돌 등)을 만족하는 해를 도출하고 시각적으로 검증

## 💻 제공되는 시뮬레이션 코드

수업 시간에 함께 푼 문제들을 시뮬레이션합니다. 코드를 실행하면 $x-y$ 평면 궤적과 속도 성분이 애니메이션으로 출력됩니다.

| 파일명 | 대상 문제 | 내용 |
|--------|---------|------|
| `ex2_5_curvilinear.py` | 예제 2.5 | $v_x = 50 - 16t, y = 100 - 4t^2$ 일반 곡선운동 궤적 추적 |
| `ex2_6_projectile.py` | 예제 2.6 | 6m 높이 울타리를 넘는 야구공(포물체) 궤적 시각화 |
| `prob2_60_airplane_drop.py` | 연습문제 2/60 | 고도 100m 등속 비행 중 투하한 우편물의 자유낙하 및 시야각 |
| `prob2_67_tunnel.py` | 연습문제 2/67 | 천장에 닿지 않고 쏘는 최대 사거리 궤적 시뮬레이션 |
