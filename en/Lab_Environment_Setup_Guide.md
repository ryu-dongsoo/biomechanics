# 🛠 Lab Environment Setup Guide

[Back to English Main](./README.md)

## 1. Overview
- This course includes dynamics analysis and visualization using **Python**.
- This guide explains how to install required editors and libraries.

## 2. Required Software
- **Python 3.10+** recommended
- **VS Code** (Visual Studio Code) recommended

## 3. Required Libraries (Python)
- `numpy`: Vector and matrix operations
- `matplotlib`: Visualization of trajectories and diagrams
- `scipy`: Numerical integration for ODEs (optional)

```bash
pip install numpy matplotlib scipy
```
