# 🛠️ Week 3 Lab: n-t, Polar (r-θ), Cylindrical, and Spherical Coordinates

> **Author / Rights Holder:** Dongsoo Ryu, Dept. of Biosystems Machinery Engineering, Jeonbuk National University (ryudongsoo@jbnu.ac.kr)

[Back to English Main](../README.md)

This folder contains Python simulation materials and 3D dynamic animations for curvilinear coordinate systems (n-t, polar, cylindrical, spherical) covered in the **Week 3 Lecture** of Biomechanics.

## 📌 Provided Simulation & Animation Scripts

### 1. Textbook Examples
- `ex2_7_car_curve.py`: Example 2/7 Car on Curvilinear Road ($n\text{-}t$ Coordinates)
- `ex2_8_pin_in_slot.py` / `ex2_8_rocket_flight.py`: Example 2/8 Rocket Flight Kinematics
- `ex2_9_robot_arm.py`: Example 2/9 Telescoping and Rotating Robotic Arm ($r\text{-}\theta$ Polar Coordinates)
- `ex2_10_radar_tracking.py`: Example 2/10 Radar Tracking of Aircraft
- `ex2_11_power_screw.py`: Example 2/11 Cylindrical Helical Motion of Collar

### 2. Practice Problems
- `prob2_101_parabolic_slot.py`: Problem 2/101 Pin in Parabolic Slot with Vertical Guide
- `prob2_105_train_curve.py`: Problem 2/105 High-Speed Train Curvilinear Motion
- `prob2_131_baseball_throw.py`: Problem 2/131 Baseball Player Throw and Radar Polar Kinematics
- `prob2_135_corkscrew.py`: Problem 2/135 Corkscrew Roller Coaster Radius of Curvature
- `prob2_136_radar_jet.py`: Problem 2/136 Radar Tracking of Jet Aircraft in Spherical Coordinates ($R\text{-}\theta\text{-}\phi$)
- `prob2_140_robot_manipulator.py`: Problem 2/140 Industrial Robot Kinematics in Cylindrical Coordinates ($r\text{-}\theta\text{-}z$)

### 3. Coordinate Systems Comparison Material
- `coord_systems_3d_comparison.py` / `.png`: 3D Cartesian, Cylindrical, and Spherical Coordinate Systems 4-in-1 Comparison Diagram

### 4. Skeleton Code
- `homework_skeleton_polar.py`: Practice skeleton script for polar coordinate acceleration

## ▶️ How to Run
Execute the scripts via the terminal. (Make sure `numpy` and `matplotlib` are installed)
```bash
python prob2_140_robot_manipulator.py
```
