## 2. Python 설치

### 2.1 다운로드

1. [https://www.python.org/downloads/](https://www.python.org/downloads/) 접속
2. 상단의 **"Download Python 3.x.x"** 버튼 클릭

> 📸 *아래와 같이 노란색 다운로드 버튼이 보이면 클릭*
> ```
> ┌─────────────────────────────────────────┐
> │  Download Python 3.x.x                  │
> │  [████ Download Python 3.x.x ████]      │
> └─────────────────────────────────────────┘
> ```

### 2.2 설치

1. 다운로드된 설치 파일(`python-3.x.x-amd64.exe`) 실행
2. ⚠️ **반드시 "Add python.exe to PATH" 체크박스 선택** (가장 중요!)
3. **"Install Now"** 클릭

> 📸 *설치 화면 하단의 체크박스 위치*
> ```
> ┌─────────────────────────────────────────┐
> │  Install Python 3.x.x                   │
> │                                         │
> │  [Install Now]                          │
> │  [Customize installation]               │
> │                                         │
> │  ☑ Use admin privileges                 │
> │  ☑ Add python.exe to PATH  ← ⚠️ 필수!  │
> └─────────────────────────────────────────┘
> ```

### 2.3 설치 확인

- Windows 검색창에 **"cmd"** 입력 → **명령 프롬프트** 실행
- 아래 명령어 입력 후 버전 번호가 출력되면 성공:

```bash
python --version
```

- 정상 출력 예시:
```
Python 3.13.3
```

> ❌ `'python'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램...` 오류 발생 시
> → [FAQ 9.1](#91-python-명령이-인식되지-않음) 참고

## 3. VS Code 설치 및 설정

### 3.1 다운로드 및 설치

1. [https://code.visualstudio.com/](https://code.visualstudio.com/) 접속
2. **"Download for Windows"** 클릭 → 설치 파일 실행
3. 설치 옵션에서 아래 항목 체크 권장:
   - ☑ `Add "Open with Code" action to Windows Explorer file context menu`
   - ☑ `Add to PATH`

### 3.2 필수 확장(Extension) 설치

- VS Code 실행 → 좌측 사이드바에서 **확장(Extensions)** 아이콘 클릭 (또는 `Ctrl+Shift+X`)
- 아래 확장을 검색하여 **Install** 클릭

| 확장명 | 설명 | 필수 여부 |
|--------|------|----------|
| **Python** (Microsoft) | Python 코드 실행 및 디버깅 | ✅ 필수 |
| **Korean Language Pack** | VS Code 한글 메뉴 | ✅ 필수 |
| **Jupyter** | 노트북 실행 (선택) | 선택 |
| **Markdown Preview Enhanced** | 보고서 미리보기 | 권장 |

> 📸 *확장 설치 화면 — "Python" 검색 후 Install 클릭*
> ```
> ┌──────────────────────────────────────────┐
> │  🔍 Python                               │
> │  ┌────────────────────────────────────┐  │
> │  │  ★ Python (Microsoft)             │  │
> │  │  IntelliSense, Linting, Debugging │  │
> │  │  [Install]                         │  │
> │  └────────────────────────────────────┘  │
> └──────────────────────────────────────────┘
> ```

### 3.3 Python 인터프리터 선택

1. VS Code에서 아무 `.py` 파일 열기
2. 하단 상태 표시줄에서 **Python 버전** 클릭
3. 설치된 Python 3.x 버전 선택

> 📸 *하단 상태 표시줄 Python 인터프리터 선택 위치*

### 3.4 VS Code 한글 설정

- **Korean Language Pack** 확장 설치 후 VS Code 재시작 → 자동으로 한글 메뉴 적용
- 수동 전환이 필요한 경우:
  1. `Ctrl+Shift+P` → `Configure Display Language` 검색
  2. **한국어(ko)** 선택 → VS Code 재시작

### 3.5 Gemini AI 코딩 도우미 설정 (Google 계정 필요)

- VS Code에서 AI 기반 코드 도움을 받을 수 있음 (무료)
- **설치 절차**:
  1. 확장 패널(`Ctrl+Shift+X`) → **"Gemini Code Assist"** 검색 → **Install**

## 4. Git 설치 및 GitHub 계정

### 4.1 Git 설치

1. [https://git-scm.com/](https://git-scm.com/) 접속 → **"Download for Windows"** 클릭
2. 설치 파일 실행 → 모든 옵션 **기본값(Next)** 유지하며 설치
3. 설치 확인:

```bash
git --version
```

- 정상 출력 예시:
```
git version 2.47.1.windows.1
```

### 4.2 GitHub 계정 생성

1. [https://github.com/](https://github.com/) 접속
2. **"Sign up"** 클릭
3. 아래 정보 입력:

| 항목 | 입력 예시 |
|------|----------|
| **Email** | 학교 이메일 또는 개인 이메일 |
| **Password** | 8자 이상, 영문+숫자 조합 |
| **Username** | `hong-gildong-2024` (영문, 기억하기 쉬운 이름) |

4. 이메일 인증 완료 후 계정 활성화

### 4.3 Git 사용자 정보 설정

- VS Code 터미널(`Ctrl+`` ` 또는 메뉴 → 터미널 → 새 터미널)에서 아래 명령어 실행:

```bash
git config --global user.name "홍길동"
git config --global user.email "gildong@example.com"
```

> ⚠️ **이름과 이메일은 GitHub 계정과 동일하게 설정 권장**

### 4.4 VS Code에서 GitHub 로그인

1. VS Code 좌측 하단의 **사람 아이콘** 클릭
2. **"Sign in to Sync Settings"** 또는 **"GitHub로 로그인"** 선택
3. 브라우저에서 GitHub 인증 완료

## 5. 실습 자료 다운로드

### 방법 A: Git Clone (권장 ⭐)

- VS Code 터미널에서 아래 명령어 실행:

```bash
git clone https://github.com/ryu-dongsoo/biomechanics.git
```

- 실행 후 `biomechanics` 폴더가 생성됨
- VS Code → **파일 → 폴더 열기** → 해당 폴더 선택

### 방법 B: ZIP 다운로드 (Git이 어려운 경우)

1. [https://github.com/ryu-dongsoo/biomechanics](https://github.com/ryu-dongsoo/biomechanics) 접속
2. 초록색 **"<> Code"** 버튼 클릭
3. **"Download ZIP"** 선택

> 📸 *GitHub에서 ZIP 다운로드 위치*
> ```
> ┌──────────────────────────────┐
> │  <> Code ▼                   │
> │  ┌────────────────────────┐  │
> │  │ Clone: HTTPS / SSH     │  │
> │  │ Open 유ith GitHub Desk  │  │
> │  │ Download ZIP ← 클릭    │  │
> │  └────────────────────────┘  │
> └──────────────────────────────┘
> ```

4. ZIP 파일 압축 해제 → VS Code에서 폴더 열기

### 자료 업데이트 (매주 수업 전)

- 이미 Clone한 경우, 최신 자료를 받으려면:

```

- ZIP으로 받은 경우 → 매주 새로 다운로드 필요

### 폴더 구조

```

├── ko/                    ← 한국어 실습 자료
│   ├── week1/             ← 1주차
│   ├── week2/             ← 2주차

## 6. Python 패키지 설치

## 7. 실습 코드 실행

### 7.1 기본 실행 방법

1. VS Code에서 해당 주차 폴더 열기 (예: `ko/week4/`)
2. 실행할 `.py` 파일 열기 (예: `ex2_12_car_intersection.py`)
3. 아래 방법 중 선택하여 실행:

| 방법 | 조작 |
|------|------|
| **버튼** | 우측 상단 `▶` (Run) 버튼 클릭 |
| **단축키** | `Ctrl+F5` (디버그 없이 실행) |
| **터미널** | `python ex2_12_car_intersection.py` 입력 |

> 📸 *VS Code에서 Python 파일 실행 버튼 위치*
> ```
> ┌─────────────────────────────────────────────┐
> │  ex2_12_car_intersection.py     ▶ ← 클릭   │
> │  ─────────────────────────────────────────  │
> │  import numpy as np                         │
> │  import matplotlib.pyplot as plt            │
> │  ...                                        │
> └─────────────────────────────────────────────┘
> ```

### 7.2 실습 진행 순서

1. 해당 주차의 **실습 매뉴얼(`.md` 파일)** 먼저 읽기
2. `ex_` (예제) 및 `prob_` (연습문제) 파일 순서대로 실행하며 궤적 및 애니메이션 관찰
3. `homework_` (과제) 스켈레톤 코드를 열고 매뉴얼의 지시에 따라 방정식 구현
4. 시뮬레이션 결과 창 스크린샷 캡처 (`Win+Shift+S`) → 보고서에 첨부

## 8. 실습 보고서 제출 (GitHub Issue)

### 8.1 제출 방식 개요

- 실습 보고서는 **GitHub Issue**를 통해 제출
- 각 주차별 보고서 양식(`.md`)을 작성한 후, Issue에 내용을 붙여넣기

### 8.2 제출 절차

#### Step 1: 보고서 작성

- 해당 주차 폴더의 보고서 양식 파일 참고
- VS Code에서 양식을 복사하여 내용 작성

#### Step 2: GitHub Issues 페이지 접속

1. [https://github.com/ryu-dongsoo/biomechanics/issues](https://github.com/ryu-dongsoo/biomechanics/issues) 접속
2. **"New issue"** 버튼 클릭

> 📸 *Issues 탭에서 New issue 버튼 위치*
> ```
> ┌────────────────────────────────────────────┐
> │  Issues    Pull requests    Actions         │
> │  ──────────────────────────────────────────│
> │  🔍 Filters ▼                              │
> │                     [New issue] ← 클릭      │
> └────────────────────────────────────────────┘
> ```

3. Issue Template이 나타나면 **"📝 실습 보고서 제출"** 선택

#### Step 3: 제목 및 내용 작성

- **제목 형식**:

```
[Week04] 202412345_홍길동_실습보고서
```

| 항목 | 형식 | 예시 |
|------|------|------|
| **주차** | `[WeekXX]` | `[Week04]` |

## 9. 자주 묻는 질문 (FAQ)

### 9.1 Python 명령이 인식되지 않음

- **증상**: `'python'은(는) 내부 또는 외부 명령...` 오류 출력
- **원인**: 설치 시 `Add python.exe to PATH` 미체크
- **해결 방법**:
  1. Python 설치 파일 재실행
  2. **"Modify"** 선택 → `Add Python to environment variables` 체크
  3. 또는 Python 완전 삭제 후 재설치 (PATH 체크 확인)

### 9.2 pip install 오류

- **증상**: `pip: command not found` 또는 권한 오류
- **해결 방법**:
  - `python -m pip install 패키지명` 명령으로 실행
  - 또는 VS Code 터미널을 **관리자 권한으로 실행** 후 재시도

### 9.3 한글 깨짐 문제

- **증상**: matplotlib 그래프의 한글이 □□□로 표시
- **해결 방법** — 코드 상단에 아래 2줄 추가:

```python
import matplotlib.pyplot as plt
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False
```

### 9.4 matplotlib 그래프 창이 안 열림

- **증상**: 코드 실행 후 그래프 창이 나타나지 않음
- **해결 방법**:
  - 코드 마지막에 `plt.show()` 가 있는지 확인
  - VS Code 설정에서 Python 인터프리터가 올바르게 선택되었는지 확인

### 9.5 Git Clone 시 인증 오류

- **증상**: `Authentication failed` 또는 `Permission denied`
- **해결 방법**:
  - GitHub 로그인 상태 확인
  - `git clone` 시 HTTPS URL 사용 확인
  - VS Code에서 GitHub 재로그인 시도

### 9.6 GitHub Issue 작성이 안 됨

- **증상**: "New issue" 버튼이 비활성화
- **원인**: GitHub 로그인 필요
- **해결 방법**: GitHub에 로그인 후 다시 시도
